# 墨页

把想法写下来，让文字慢慢成形。

墨页是一张安静的 Markdown 书桌。你可以像平常一样输入中文，也可以用熟悉的符号整理结构。输入 `**重要的句子**`，文字会呈现为 **重要的句子**；把光标移回其中，继续修改。

## 从第一段开始

写下今天的一件小事、一条开发笔记，或者一个还没有想清楚的问题。段落之间留一点呼吸的空间，思路也会更清楚。

- 用标题划分主题
- 用列表记录步骤
- 用引用留下值得回看的话

> 好的工具，应当让你更容易继续写下一句。

## 给想法一个结构

| 内容 | 适合的表达 |
| :--- | :--- |
| 一段思考 | 普通段落 |
| 一组比较 | 表格 |
| 一项计划 | 任务列表 |

- [x] 写下第一个想法
- [ ] 补充一个例子
- [ ] 回头读一遍

你也可以记录代码：

```csharp
var idea = "从一个小问题开始";
Console.WriteLine(idea);
```

## 公式与图表

一点点持续积累，也可以写成一个简单的式子：$S_n = \sum_{i=1}^{n} a_i$。

```mermaid
flowchart LR
    A[记录想法] --> B[整理结构]
    B --> C[继续书写]
```

公式和图表的显示资源随程序提供，断网时也能继续使用。想检查全部语法，可以打开同目录下的 `完整语法验收.md`。

## 常用操作

Windows 和 Linux 使用 **Ctrl**，macOS 使用 **Cmd**。

| 操作 | 快捷键 |
| --- | --- |
| 打开 | Ctrl/Cmd + O |
| 保存 | Ctrl/Cmd + S |
| 另存为 | Ctrl/Cmd + Shift + S |
| 源码模式 | Ctrl/Cmd + / |
| 查找 | Ctrl/Cmd + F |

文档保存为普通 `.md` 文件。本地图片与资源文件夹一起保管，之后可以换一个设备，继续写下去。
