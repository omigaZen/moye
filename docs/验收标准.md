# 墨页当前验收标准

用户将目标提高为：支持最新版 Typora 全部用户可配置设置，并使全部合法设置下的行为与同平台原版一致。具体设置范围、组合验证及发布门槛以[Typora设置兼容性](Typora设置兼容性.md)为准。下表 E01—E30 保留为初始操作样本，不是完整范围，也不构成设置兼容通过证据。当前为 0.5.0 开发预览，72 项设置（70项可见、2项方案元数据）及新增合法值见[0.5.0设置进展](0.5.0设置进展.md)；实际执行结果与历史证据见[验收报告](验收报告.md)。只有执行者记录了环境、步骤和证据，才可将项目改为“通过”或“失败”。构建成功、单元测试通过、模拟组合事件，均不能替代原版对照、真实平台和真实中文输入法测试。
