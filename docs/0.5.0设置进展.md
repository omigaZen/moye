# 墨页 0.5.0 设置与交互进展

更新日期：2026-10-25（Asia/Shanghai）。本版继续保留最新版 Typora 全设置及所有合法配置行为一致、Telari 42 个公开行为组的目标；墨页自测不等于原版差分验收。

设置由68项增至 **72项（70项可见、2项方案元数据）**，命令由33个增至 **36个**。这些是墨页的配置数量，不是原版设置总数。原有键与默认值见0.3.0及0.4.0进展；仍保持schemaVersion 1，旧合法配置补入下列默认值。

| 新键 | 合法值 | 墨页默认值 | 效果 |
| --- | --- | --- | --- |
| `ui.language` | `zh-CN`、`en-US`、`system` | `zh-CN` | 即时中英文切换；system选择中文系统用简体中文、其他系统用English。组合输入结束后才应用外部变化。正文、文件名和用户方案名不翻译 |
| `typography.punctuationCompression` | 布尔值 | false | 压缩全角东亚标点的显示空白，不写入字符；编辑态按实际浏览器能力，阅读态按可支持的字形几何；路径/URL等排除 |
| `reading.nextDocumentPrompt` | 布尔值 | true | 到末尾且有同类邻居时显示下一篇；可关闭，空格不自动跳到另一文件 |
| `reading.txtPreset` | `inherit`、`book`、`compact` | `inherit` | 独立纯文本阅读排版；不改变全局书写设置和文件内容 |

新增命令 `recent`、`system-preview`、`close-window` 均默认未绑定，避免占用旧自定义快捷键。`close`仍保留原Ctrl/Cmd+W绑定：有多个工作区标签时关闭当前标签，剩一个时关闭窗口；真正系统窗口关闭不被误解释为关闭一个标签。关闭脏文档仍先确认，取消不改变正文、选区或撤销。

最近文件使用独立有界列表，支持搜索、键盘打开、移除与清空。单击预览不堆入历史，保留、实际打开和成功保存会登记；清空只删列表记录，不删文件。不可用文件给出状态，跨重启保留。

普通打开的文件也可按同目录自然顺序前后导航，不必先选择整个工作区；Markdown与TXT分组，边界不循环。原生接口只使用当前文档的父目录及不透明条目，不接受渲染器给出的任意文件路径。

长篇纯文本在262144个UTF-16单元阈值后按窗口显示，每窗目标65536 UTF-16单元及最多256行；为保留常见字形簇，窗口边界最多延伸64个UTF-16单元。章节大纲、首尾、分段、全文查找、普通选区和整篇复制使用完整原文索引。它是显式分段阅读，不是整篇连续滚动。大源码锚点改用有界比例回退，不为估算一行而排版全文副本。

整篇TXT导出会另建完整只读根，最多200万UTF-16单元及约2万段落；超过预算明确拒绝，不会偷偷只导出当前窗口。可将需要的章节另存为较小文件后导出。PDF对话框新增纵横方向及8—30毫米整数页边距；原有纸张、配色等仍可用。

Linux系统缩略图由独立只读进程生成，可在发布包的“更多操作→系统缩略图”显式启用或移除。预览有读取、绘制、图片和超时预算，超限显示源码或开头提示；本地KaTeX不冒充MathJax与所有图表一致。macOS Quick Look提供扩展源码和构建脚本，仍需对应SDK、签名及Finder实测；Windows Explorer提供程序尚缺。

窗口保存normal bounds、maximized与显示器标识，不把全屏尺寸当作普通窗口尺寸；移除屏幕或降低分辨率后限制在当前workArea。纯几何测试与无头窗口标志检查不能代替真实多屏、手势、系统输入法或原生全屏验证。

实际运行结果、性能、四平台分发与剩余差距以 `验收报告.md`、`Telari体验对照.md` 为准。语言细节见 `语言支持.md`；系统预览的源码、注册和原生构建说明见 `native/system-preview/README.md`。
