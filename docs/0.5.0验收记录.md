## 最终性能与内存

最终性能仅在源码、四包构建、实际Linux包回归及归档审计完成后，对冻结的实际包执行一次；**没有为了取得通过而重复该版本最终测量**。旧门槛保持启动/打开≤2000ms、输入P95≤50ms。后续独立内存快照不重跑或替代延迟门槛。

| 指标 | 0.4.0历史样本 | 0.5.0最终样本 | 门槛 |
| --- | --- | --- | --- |
| 新进程启动至ready | 851.1 ms | 780.4 ms | 2000 ms |
| 长Markdown打开至可编辑 | 645.7 ms | 552.5 ms | 2000 ms |
| 键盘beforeinput至下一帧P95 | 19.2 ms | 23.9 ms | 50 ms |
| 页面插入至下一帧P95 | 19.1 ms | 17.0 ms | 50 ms |
| Playwright端到端键盘P95 | 34.3 ms | 44.5 ms | 辅助诊断，包含传输 |

样本为`samples/长文性能验收.md`：308790字节、108630码点、100080个汉字、100代码块与20本地图片。字体加载、内容/保存完整性、光标可见及不跳回文首检查通过。时延包括自动化采样条件，非物理键盘到屏幕延迟；新进程启动不等于清空OS文件缓存。这是两个单次记录，不能推导统计上的性能提升或退化。

独立Linux快照中，所采集4个Electron进程的RSS合计688496KiB、PSS合计458898KiB（约448.1MiB）。RSS可能重复计算共享页；不是整个进程树峰值、跨平台上界或内存达标门槛。本机Electron内存API的working-set为零，因此没有将其当成零内存结论。

长TXT另列功能预算样本，未替换原Markdown门槛：实际包打开4726022字节/2239862 UTF-16单元/180章耗时 **643.6ms**（独立5000ms预算），远章跳转28.6ms；仅挂载当前窗口，整篇复制SHA256一致。稳定后所采集进程PSS合计460720KiB，亦不是峰值。最初116秒及中间2297.5ms的失败/诊断记录保留在`artifacts/reading-longform-before-*.json`，没有删除历史问题。

3. 大TXT为显式分段阅读，阈值262144 UTF-16单元，窗口目标65536单元/最多256行，字形簇边界最多额外64单元；不是整篇连续虚拟滚动。编辑仍是完整原生textarea；整篇TXT导出最多200万UTF-16单元/约2万段，超出明确拒绝。
4. 段落优化保留4096单元/段、700词元、18000总字符、100ms总/45ms单段预算；数学、代码、RTL、生成内容及复杂盒模型回退。全字体/语言、任意CSS及复杂分页/公式质量仍未与原版等价。

6. 语言仅简中/英文/system，未实现Telari全部语言。真实系统输入法、屏幕阅读器、触控手势、多屏/全屏、Windows/macOS实机、签名/公证与更新流程仍待完成；本机原生workArea仅1×1且未进入真实全屏，不能拿无头标志冒充原生窗口验收。
