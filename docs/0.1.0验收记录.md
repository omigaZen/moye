# 墨页 0.1.0 开发预览验收记录

日期：2026-10-23。交付状态：已实现首版功能并提供四种平台便携包；**尚未通过全部正式验收门槛**。Windows/macOS 实机、真实系统输入法和固定 Typora 版本逐步对照仍待执行。

用户后续明确要求支持最新 Typora 的所有设置及其行为。当前官方稳定版为 1.14.10；新的完整目标见 [Typora设置兼容性](Typora设置兼容性.md)。本报告保留为 0.1.0 历史功能证据，以下通过项不能换算为 Typora 设置兼容覆盖率。当前没有完整设置清单或原版各平台运行对照证据，新目标尚未达成。

## 已执行的验证

- Node 文件与文档状态测试：50 项通过。覆盖原子保存、BOM/换行、外部修改冲突、草稿恢复隔离、旧快照、图片引用迁移、图片碰撞和符号链接边界。
- 真实 Electron 45 / Chromium 的 Linux headless 操作测试：49 项通过。快速输入后保存/切换、即时撤销重做、中文组合事件保护、重复段落与反向选区、格式和链接复制、可见内容查找替换、表格/列表键盘与图形化行列/对齐工具、图片落盘和保存重开、目录与脚注往返等。各用例结果保存在 `tests/*-report.json`。
- 完整语法样本：8 类 Mermaid、5 个数学公式、本地中文空格路径图像、YAML、脚注、TOC、高亮、上下标和常用 HTML。自动化阻止所有 HTTP(S) 请求，图表、公式及本地资源仍正常显示；错误图表和公式保留源码，修正后恢复。
- 实际 Linux 打包产物：从 `Moye` 二进制和 ASAR 启动并检查离线资源，结果保存在 `tests/packaged-linux-report.json`。表格切源码与源码查找的光标视口回归也在实际发布包通过；四平台 ASAR 一致，660 个应用与资源文件逐字节匹配源码。构建和测试脚本随源码提供。
- 视觉检查：已检查实际打包程序的浅色、深色、源码、表格工具、公式与图表画面，以及长文中部输入前后视口。测试内容均为项目样本。

## 性能样本与测量

使用生成的长文：约10万中文字符、100个C#代码块、20张本地图像。最终测量运行的是实际 Linux 发布包，已核对运行中 ASAR 的 renderer/main 哈希与源码一致。环境为 Linux x64、Electron 45、1280×860 自动化视口；硬件和容器限制记录在 `artifacts/performance-report.json`。测量不是实体显示器呈现时间。

| 指标 | 本轮结果 | 说明 |
| --- | ---: | --- |
| 启动到可用 | 621 ms | 包含运行时启动、自动化连接和中文字体预载 |
| 打开长文到可编辑 | 590 ms | 应用已启动；不含人工选择文件时间 |
| 首次字符 beforeinput 到下一帧 p95 | 32.1 ms | 本轮低于50ms目标；需要目标电脑复测 |
| 页面插入文本到下一帧 p95 | 30.3 ms | 不含外部自动化IPC |
| 外部自动化输入到帧回传 p95 | 51.9 ms | 仍高于50ms，原报告保留 `pass: false` |
| 输入完整性 | 通过 | 60次输入完整且唯一，原文未丢失 |
| 长文中部视口 | 通过 | 采样未发现重置到文首；不能证明所有中间帧无闪动 |
| 本地图像与高亮 | 通过 | 20/20图像，100个代码块 |

初版逐字全量序列化和中文字体首次分片加载曾使输入延迟超标；已改为立即标记修改、在保存/切换前同步内容，并在启动时预载中文字体。实际包截图额外发现并修复源码切换和查找后光标离屏，已增加视口回归。优化前报告保留在 `artifacts/`。本轮 `editorInteractionPass: true`，完整保守评估仍为 `pass: false`；没有将失败字段改为通过。

## 参照与差异

当前实现以2026-10-23读取的 Typora 官方 [Quick Start](https://support.typora.io/Quick-Start/)、[Markdown Reference](https://support.typora.io/Markdown-Reference/) 和 [Table Editing](https://support.typora.io/Table-Editing/) 的公开行为说明为参照。尚未取得固定版本 Typora 的逐步运行记录，因此不宣称每个键鼠边界已经逐项一致。

- 表格 Enter 与 Shift+Enter 均为单元格内换行；Ctrl/Cmd+Enter 在当前行下增加行，末尾Tab增加行。
- 图形化和源码编辑使用同一Markdown文档。即时渲染内核可能将列表符号、表格空白或HTML布局规范化；未编辑直接保存保留原始字节。未知HTML与注释已验证在无关编辑后仍保留，尚不承诺所有第三方扩展语法的字节级保真。
- 脚注悬停预览，Ctrl/Cmd+单击跳转定义，再用底部按钮返回引用。
- 跨目录另存复制文档目录内的相对图片。目录外图像、符号链接和超25MB图像改用原位置的file引用；移动文件后仍需保管这些外部资源。
- 0.1.0 未实现文件树、完整导出和主题兼容等能力；涉及新目标的相关设置仍须实现，此历史记录不再作为排除理由。
