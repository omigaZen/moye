# 墨页 0.3.0 开发预览验收记录

日期：2026-10-24（Asia/Shanghai）。总体状态：**尚未达到最新版 Typora 全部设置及全部合法配置下行为一致的目标**。自有设置数、用例数与原版设置完整性、差分通过率分别记录，不相互换算。

## 本轮实现

现有 47 项墨页应用设置，比 0.2.0 增加 13 项；设置的合法值、墨页默认值、依赖和生效时机见 [0.3.0设置进展](0.3.0设置进展.md)。原版完整设置总数和运行默认值仍未确定。

- 专注模式改为弱化非当前块/行，保留界面控件，支持段落、标题、嵌套列表、表格、代码及源码行；显示层不修改可编辑 DOM。打字机模式支持鼠标定位始终居中与仅输入居中，以及文首/文尾居中。
- 新增 27 个现有命令的自定义快捷键，支持重映射、禁用、语义冲突校验、持久化和菜单更新；清除被替换的内核快捷键，组合输入、AltGraph 和外部输入控件不触发文档格式操作。使用真实 Electron sendInputEvent 验证原生与编辑区路由，而非仅靠绕过菜单的 CDP 输入。
- 新增输入时智能引号、破折号与省略号转换；保留代码、公式、YAML、HTML、URL、源码、粘贴与未提交组合输入。新输入横线、YAML 与 HTML 注释有结构保护。此 ASCII 结构保护不等于原版完整 Unicode 标点解析重映射。
- 新增连续空白与单个换行显示选项、独立 math 围栏预览、MathJax none/AMS/all 编号和 physics 扩展。关闭围栏公式不影响行内和 $$ 公式；切换保持原文、dirty、光标/反向选区及保存结果。
- 图片支持相对目录模板、相对/绝对/默认路径、./ 前缀、可选编码、本地文件适用范围；位图仍落盘。图片导入和 Save As 资源迁移使用完整临时写入后独占发布。可读空格、Unicode、括号、反引号及必要 URL 分隔转义的保存/重开/模式往返已检查。
- 大纲缓存仅在实际标题输入、节点身份、DOM 索引、设置及模式保持不变时复用，保留正常块解析、撤销与目录调用。标题修改、插入、删除、重排、级别、ID、样式、模式和重新载入均使缓存失效；异常配置回退原生成器。

同时修复重载时最后的输入控件焦点恢复丢失反向选区方向、math 围栏开关误伤其他公式，以及智能破折号打断新横线/YAML 等实测问题。

## 原版基准与未完成范围

本轮复核 [官方稳定发布页](https://typora.io/releases/stable?no-warning=) 顶部仍为 1.14.10。原先实际取得的官方 Linux x64 包为 1.14.9；不将其改称最新包。它因生产调试参数保护和本环境 Unix socket 限制未取得可运行 UI 基线，未绕过保护。Windows/macOS 原版也未完成同平台运行对照。

`tests/typora-reference-report.json` 保留原版获取和启动证据；`tests/typora-settings-metadata.json` 的 10 项高级默认声明及 226 个设置/组/选项标签候选不是完整设置清单，不等于运行默认值或行为已证实。原版二进制未进入源码或发布包。

本轮实现参考官方 [专注与打字机](https://support.typora.io/Focus-and-Typewriter-Mode/)、[快捷键](https://support.typora.io/Shortcut-Keys/)、[智能标点](https://support.typora.io/SmartyPants/)、[图片](https://support.typora.io/Images/) 与 [数学](https://support.typora.io/Math/) 文档；公开文档不替代最新原版操作序列。

高级配置与完整 Typora 主题/CSS DOM 兼容、完整命令目录与 conf.user.json/系统快捷键兼容、智能标点仅渲染转换及一般 Unicode 重映射/系统引号样式、严格/legacy 解析、图片 YAML/上传/在线规则/自动目录重命名、文件树及导出关联能力仍未补齐。专注的显示层与任意 Typora CSS 不等价。系统拼写字典、跨应用剪贴板、真实中文输入法、Windows/两类 Mac 与各平台性能仍待实机验证。这些仍属于目标范围，不作排除。

完整门槛见 [Typora设置兼容性](Typora设置兼容性.md)。0.2.0 记录见 [0.2.0验收记录](0.2.0验收记录.md)。
