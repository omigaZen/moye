# 墨页 0.3.0 设置实现进展

更新日期：2026-10-24（Asia/Shanghai）。当前为开发预览，目标仍是最新稳定版 Typora 的全部设置及相应编辑行为一致。墨页现有 **47 项应用设置**，比 0.2.0 增加 13 项；这不是 Typora 的设置总数。原版完整设置枚举、默认值和逐步行为对照尚未完成，不能据此宣称全量兼容。

## 当前实际变化

- 专注模式在书写区弱化非当前语义块，在代码、公式及 YAML 编辑区聚焦当前行；源码模式弱化当前视觉行以外区域。书写区采用 CSS Custom Highlight，源码区使用显示遮罩，不改写可编辑 DOM。它们不是 Typora 主题 DOM 或用户 CSS 的兼容层。
- 打字机模式自行计算光标位置并滚动；新增鼠标选中后是否继续居中的选项。布局和滚动不写入文档。
- 新增 27 个稳定命令 ID 的快捷键配置，原生菜单和编辑区采用同一配置；新增书写模式输入时的智能引号、破折号和省略号转换。智能标点尚不包含原文渲染转换、一般解析重映射及系统引号样式选择。
- 新增连续空白与单个换行的显示选项、独立的数学代码围栏预览、MathJax AMS 编号规则和 physics 扩展。
- 图片新增文档相对目录模板、路径形式、相对前缀、转义和本地文件适用开关。插入使用完整临时文件发布，避免留下半张图片；这不等于批量图片与文档保存形成跨文件事务。

0.2.0 的历史实现和测试记录保留在 [0.2.0设置进展](0.2.0设置进展.md)。本文件描述当前代码行为；实际执行结果、发布包状态和性能测量以 [验收报告](验收报告.md) 为准。

组合键允许 Ctrl、Command/Meta、Alt/Option、Shift、CmdOrCtrl 等别名和一个受支持的字母、数字、标点或 F1—F24 键；加号键写作 `Plus`。普通文字键要求 Ctrl、Command 或 Alt 修饰键。固定编辑导航键以及剪切/复制/粘贴、全选、缩放和部分系统快捷键被保留。会校验与默认命令及用户覆盖后的重复绑定；若要占用其他命令的默认键，须在同一份 JSON 中重绑或禁用该命令。

通过快捷键触发的编辑命令仅在编辑区获得焦点时执行；查找、偏好设置和原生文字控件保留各自按键处理。组合输入、AltGraph 与已标识的死键不分派命令。实体键盘布局、操作系统拦截和全部快捷键与原版的对照仍待实机验证。

## 输入、图片与设置保存的边界

智能标点只处理书写模式的单字符 `insertText`。源码模式、粘贴、组合输入、代码/公式/YAML/HTML、链接目的地址等保持字面输入；它不重写打开的原文。`--` 在 Windows/Linux 转为短破折号，在 macOS 转为长破折号；继续输入第三个连字符使用长破折号，`...` 转为省略号。单独的连字符行按 Markdown 结构保留。可撤销转换不等于原版全部撤销分组已验证。渲染转换、一般 Unicode 解析重映射、系统文本替换与引号样式仍待实现或对照。

从文件选择器引用原图时，auto/absolute 路径允许未命名文档；选择 relative 仍需先保存。复制、拖放和剪贴板位图需先保存文档。资源目录只支持文档内相对路径及 `${filename}`；例如 `assets/${filename}`。已有 Markdown 中的图片不会因改设置自动重写。另存到不同目录时，识别到的文档目录内相对图片按原相对位置复制；上级路径、符号链接和超限图片转为原位置文件 URL，缺失图片保留原引用。迁移只处理识别到的图片目的地址，不表示任意 Markdown/HTML 路径解析完全兼容。

设置文件仍为 `schemaVersion: 1`。0.2.0 的有效墨页设置可读取/导入，缺少的 13 项补为当前墨页默认值；未声称旧配置与新配置的全部行为相同。设置在原生进程校验、原子写入后才发布到界面，保留版本冲突检查；无效多键更新/导入和写入失败不会部分更新当前设置。未知键、非法值、超过 64 KB 的整份设置文件均被拒绝。损坏本地配置保留为 `settings.invalid-...json` 后使用默认值。恢复默认采用二次确认，并恢复全部 47 项墨页默认值。

所有 Markdown 和数学设置均需显式重新载入。重新载入保留原文、修改状态、模式、光标/选区和滚动位置，撤销历史重新开始；组合输入期间不执行。重新启动也会采用已保存设置。
