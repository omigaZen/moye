# 墨页 0.2.0 设置实现进展

更新日期：2026-10-23。当前交付定位为开发预览。目标仍是最新稳定版 Typora 的全部设置及相应编辑行为一致；本轮已实现 34 项墨页应用设置，**尚未确认它们与原版设置逐项等价，也没有完成原版设置总量枚举**。34 项不是 Typora 设置总数。

## 本轮实际变化

- 新增可搜索的偏好设置窗口，支持分类、键盘操作、恢复默认二次确认和原生文件选择器导入/导出。入口为更多菜单或 Ctrl/Cmd + 逗号。
- 设置由原生进程校验并原子保存，包含版本冲突检测、无效配置保留、写入失败回滚；重启后恢复。未知键和非法值不会部分生效。导入导出格式为墨页设置 JSON，尚不是 Typora 配置兼容导入。
- 外观、部分编辑、代码、拼写和图片策略已接入实际行为；Markdown/数学更改先保存，再由明确的“重新载入”操作应用。重新载入保留原文、修改状态、模式、光标/选区和滚动位置，撤销历史重新开始。
- 默认数学引擎改为离线 MathJax 4.1.3，提供本地宏、编号和附加 TeX/字体资源，KaTeX 可选。原版全部数学行为尚未验证。

## 参考版本获取结果

官方稳定发布页在 2026-10-23 列出的顶部版本为 **1.14.10**。从官方 Linux x64 浮动链接实际下载的原始包，版本元数据为 **1.14.9**，与官方 APT 索引 amd64 最新项 1.14.9-1 相符；不能据此宣布已取得 Linux 1.14.10。下载包 SHA256：

`06f03e6dee1f48126e62680ecd8e0551053681951d802d8ee433f96dae9fa045`

原版拒绝生产模式调试启动；普通启动受本环境 Unix socket 限制阻断。未绕过原版保护，因此没有实际设置 UI、默认值或逐步编辑记录。Windows/macOS 也没有原版运行对照。完整证据为 `tests/typora-reference-report.json`；原版二进制不进入墨页源码或发布包。

## 测试证据与当前界限

当前新增验证包括设置存储的 Node 测试、实际 Electron 原生接口测试、设置窗口/编辑效果测试，以及断网条件下的 MathJax 测试。文件与核心编辑回归继续保留。测试脚本与逐项结果在 `tests/`；最终通过总数、发布包验证和性能样本以 [验收报告](验收报告.md) 为准。

这些测试验证墨页自身的功能和回归，不等于与 Typora 对照。系统拼写字典、真实中文输入法、Windows/macOS 原生行为、任意字体/CSS、所有配置组合，均没有因此获得通过结论。自动编号和可选参数宏依赖 MathJax；代码块默认语言目前覆盖工具栏创建入口，不能视为 Typora 全部创建方式的默认语言策略已经兼容。

当前“专注模式”提供隐藏界面控件的布局，尚未实现 Typora 聚焦当前段落、弱化周边内容的同等显示行为；该差距仍须补齐并对照。
