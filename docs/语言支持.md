# 界面语言

0.5.0 新增简体中文、English 和“跟随系统”。默认保持简体中文，以保留旧版设置的行为；跟随系统时，中文系统使用简体中文，其他语言系统使用 English。只保存 `ui.language`，不向网络服务发送文本，也不下载语言文件。

应用自有的菜单、设置标签与说明、搜索、对话框、浮层、状态、ARIA 描述及编辑器工具词汇支持即时切换。设置搜索同时包含中英文词汇。语言变化复用当前编辑器和设置面板，不通过重建面板丢弃草稿；编辑器组合输入期间由主集成延迟应用配置变化。系统原生文件选择器中由操作系统提供的目录名称、系统按钮或辅助功能界面仍由操作系统管理。

文档正文、源码、代码、数学公式、文件名与绝对路径、工作区目录和大纲条目、自定义排版方案名和颜色主题名、输入框的实际值均视为用户数据。即使它们恰好叫“保存”或“文件”，也不会当作界面标签翻译。自定义选项只翻译程序添加的“自定义”“深色”等后缀，不改变名称本身。排版样例保留原有中英混排示例，以便比较字体；它们不是当前文档。

`src/i18n.js` 只观察受限的应用 UI 容器，既不观察正文子树，也不遍历编辑器长文做词汇替换。正文内由程序创建的代码复制按钮须显式注册；公式/图表说明可以只注册其 ARIA/状态属性。离开文档后会清理脱离 DOM 的注册项。翻译使用文本节点和属性赋值，不把文件名或提示当作 HTML 执行。原生菜单项可通过内部 `i18nUserContent` 标记保留字典建议或文件名。

语言目录位于 `src/locales/en-US.js`，设置定义本身继续使用稳定的配置键、枚举值和中文 canonical 文案。应用译文为独立实现；编辑器工具词汇复用已随包的 Vditor 中英文词表，其许可证见第三方声明。不声称已经支持 Telari 的所有语言或完成原版逐项语言差分。

验证脚本：`tests/i18n.test.cjs` 检查设置字段覆盖、模板中的文件名、原生菜单/对话框与配置值保护；`tests/editor-i18n.cjs` 在真实 Electron 应用中检查即时往返、原文/选区/撤销、双语搜索、用户名称、组合输入延迟及重启持久化。实际运行状态以本轮验收报告为准。
