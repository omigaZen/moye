# 墨页 Moye

墨页是一款面向 Windows、macOS 和 Linux 的本地 Markdown 桌面编辑器。默认采用即时渲染：在正文中输入 Markdown，直接看到排版，移动光标到内容中继续修改。

## 开始书写

1. 启动墨页，打开随附的 `samples/欢迎.md`，或新建文档。
2. 直接输入正文。使用 `# 标题`、`**粗体**`、`- 列表` 等 Markdown 写法组织内容。
3. 在需要检查原始语法时切换源码模式；阅读时切换顶部“阅读”，完成后返回书写。
4. 保存为普通 `.md` 文件。文件可交给其他 Markdown 软件继续编辑。

当前为 0.4.0 开发预览。这里列出当前使用路径；实际通过的项目以随包验收记录为准。跨平台构建成功不等同于各平台已经实测，当前也尚未达到 Typora 全设置与编辑行为一致的验收目标。0.4 新增体验的来源、实现与边界见 [Telari体验对照](Telari体验对照.md)。

## 常用快捷键

macOS 使用 `Cmd`，Windows 和 Linux 使用 `Ctrl`。

| 操作 | 快捷键 |
| --- | --- |
| 新建文档 | Ctrl/Cmd + N |
| 打开文档 | Ctrl/Cmd + O |
| 保存 | Ctrl/Cmd + S |
| 另存为 | Ctrl/Cmd + Shift + S |
| 切换源码模式 | Ctrl/Cmd + / |
| 切换阅读模式 | Ctrl/Cmd + Alt + R |
| 查找 | Ctrl/Cmd + F |
| 粗体 | Ctrl/Cmd + B |
| 斜体 | Ctrl/Cmd + I |
| 插入链接 | Ctrl/Cmd + K |
| 撤销 | Ctrl/Cmd + Z |
| 专注 / 打字机模式 | F8 / F9 |
| 偏好设置 | Ctrl/Cmd + , |

重做、剪切、复制、粘贴及全选也可通过系统菜单使用。偏好设置的“快捷键”分类可用命令 ID 到组合键的 JSON 修改当前 33 个命令，例如 `{"focus":"F7","bold":"Ctrl+Alt+B","typewriter":""}`；空字符串禁用对应快捷键。未知命令、重复分配和固定系统/编辑键冲突会被拒绝。0.4 新增 `reading`、`workspace`、`previous-file`、`next-file`、`export-pdf`、`export-image`，六项默认没有快捷键，避免占用旧版自定义快捷键，可按需分配；其余命令表见 [0.3.0设置进展](0.3.0设置进展.md)。这些是墨页命令 ID，不直接接受 Typora 配置。快捷键遇到输入法正在选词时，应先完成或取消选词。

## 阅读与 TXT 长文

点击顶部“阅读”，或按 `Ctrl/Cmd + Alt + R`。阅读模式显示独立的只读正文；选取和复制不会修改原文，返回书写时保留进入前的选区、滚动位置和撤销历史。点击“返回书写”或按 Esc 退出；源码模式也可以进入阅读，再返回原模式。

先点击阅读正文，再使用下列按键：

| 操作 | 按键 |
| --- | --- |
| 向后翻页 | 空格、PageDown |
| 向前翻页 | Shift + 空格、PageUp |
| 文首 / 文末 | Home / End |
| 全选阅读正文 | Ctrl/Cmd + A |
| 返回书写 | Esc |

翻页按实际视觉行定位，尽量保留两行上下文；末页受文档边界限制。设置搜索框、按钮及其他输入控件保留自己的按键行为。可在“阅读”设置开启自动隐藏工具栏：指针靠近正文顶部或键盘聚焦工具栏时浮现，正文不会上下移动。

左侧大纲、文内目录、章节链接和脚注可跳转到对应位置，阅读工具栏的“返回”回到跳转前的位置。默认记住每个文件的阅读位置；记录只包含位置标记，不保存正文。更改字号、正文宽度或窗口大小时，尽量保留当前所读文字在窗口中的位置。

TXT 默认按字面文本阅读，`#`、反引号和 HTML 文字不会自动变为 Markdown。“TXT 文件阅读方式”可改为按 Markdown 阅读，或将所有文档按纯文本阅读；这只改变阅读呈现。纯文本可选择空行分段或逐行分段，并识别“第一章”“Chapter 1”等章节大纲；不匹配的标题仍作为正文显示。纯文本呈现与章节识别不会将结果写回文件。

阅读表格可复制整表或选定矩形区域，纯文本使用制表符分列，方便粘贴到电子表格。阅读公式复制保留其 Markdown 分隔符；关闭公式预览时保留源码。普通复制同时提供可用的富文本格式；“复制时将纯文本格式设为 Markdown”只改变剪贴板的纯文本部分。

## 工作区与标签

从更多菜单或系统“文件”菜单选择“打开文件夹”。左侧工作区展示本地 Markdown 与 TXT 文件；文件夹按需展开，顶部输入框按文件名、相对路径或扩展名筛选。点击刷新可重新读取文件树，磁盘变化也会触发更新。

单击文件使用预览标签；双击或按 Enter 将它保留为常驻标签。可保留多个标签，点击标签切换，点击标签上的 × 关闭。存在未保存修改时，先按提示保存、放弃或取消；不要将预览标签理解为另一份已保存副本。

工作区“上一篇”“下一篇”以及文件菜单的同目录命令按该目录内的文件顺序切换。文件树可用上下方向键移动、左右方向键展开或收起、Home/End 到首尾、Enter 打开。工作区只浏览已选择的根目录；不可用或越界的链接会跳过并提示。

## 导出 PDF 与图片

在更多菜单或系统“文件”菜单选择“导出 PDF”或“导出图片”。导出使用只读排版快照，可包含当前未保存的正文，并等待阅读公式渲染；不会写回 Markdown。选择保存位置后才生成目标文件。

- **宽度**：当前正文宽度、手机 400 px、平板 672 px，或自定义 400—4096 px。导出会按目标宽度重新排版。
- **PDF**：选择 A4、Letter、A5 或 Legal 纸张，按页面分页。
- **PNG**：导出整篇长图，可选 1×、2× 或 3×；文档过长或像素总量过大时会拒绝，并提示降低宽度/倍率或改用 PDF。
- **配色**：保留当前配色，或使用白纸；PNG 默认当前配色，PDF 默认白纸。

导出只使用允许的本地与内嵌资源，不临时下载远程图片。检查导出提示与成品；缺失的图片或字体、复杂表格和特殊公式仍可能影响版面。PDF/PNG 是排版结果，后续编辑请保留原始文档和资源目录。

## 编辑常见内容

- **列表**：输入 `- `、`1. ` 或 `- [ ] `。Enter 继续下一项，空项 Enter 退出；Tab 和 Shift + Tab 调整层级。
- **代码**：使用三个反引号围住代码，可附加 `csharp`、`python` 等语言名。
- **表格**：使用 Markdown 表格或编辑器的表格入口创建，再直接修改单元格。将光标放入单元格后，底部显示增删行列、对齐与删除表格工具；表头保留为必需行。Tab/Shift + Tab 在单元格间移动；在最后一个单元格按 Tab 自动新增行；Ctrl/Cmd + Enter 在当前行下新增行；Enter 或 Shift + Enter 在单元格内换行。
- **公式**：`$E=mc^2$` 用于行内公式，独立的 `$$` 围栏用于块公式。
- **图表**：使用语言名为 `mermaid` 的代码块。修改代码后查看图表，语法错误时返回代码继续修正。
- **目录**：使用独立的 `[toc]`，并通过文档标题维护层级。
- **脚注**：在正文使用 `[^名称]`，在文末用 `[^名称]: 脚注内容` 定义。悬停引用可预览，Ctrl/Cmd + 单击跳转定义，再用底部“返回脚注引用”回到原处。

完整示例见 `samples/完整语法验收.md`。HTML 和 Mermaid 的具体覆盖范围见 [语法范围](语法范围.md)。

表格设置可选正文、窗口或按内容宽度，网格或三线表，以及整体靠起始边、居中或靠结束边。宽表可在表格区域横向滚动。复制工具支持整表和矩形区域，阅读模式只提供复制操作。代码设置可分别开关语法高亮、语言角标、行号和自动换行；代码块可复制代码，源码着色仅作用于显示层。

## 专注、打字机与智能标点

专注模式弱化当前段落、列表项、表格单元格等语义块之外的内容；代码、公式及 YAML 编辑区聚焦当前行。源码模式显示当前视觉行，周围区域变淡。这些显示效果不写入 Markdown；它们尚不代表 Typora 主题 DOM 或自定义 CSS 已兼容。

打字机模式将光标滚动到书写区中部。开启“打字机模式下始终居中光标”后，鼠标选择和光标移动也触发居中；关闭后仅输入触发。该选项只在打字机模式开启时有效。

智能引号、破折号与省略号默认关闭，开启后转换书写模式中的后续单字符输入。源码模式、粘贴、组合输入和代码/公式/YAML 等内容保持字面输入，不批量改写已有文档。转换可撤销。一般渲染转换、解析重映射和操作系统引号样式仍待补齐，不应将它视为全部 Typora 智能标点行为。

## 图片与移动文档

文件选择器插图可复制到文档资源目录，或引用原位置。“对本地文件图片应用复制规则”关闭时，文件选择器引用原图。拖放、截图和剪贴板图片以字节流导入，仍需先保存文档，再保存图片文件。

- **资源目录**默认 `${filename}.assets`，可改为 `assets/${filename}` 等文档内相对目录；`${filename}` 替换为 Markdown 文件名（不含扩展名）。不支持绝对目录、父级跳出和符号链接。更改目录不会搬迁已有图片。
- **路径形式**默认 auto：复制图片使用相对路径，引用原图使用文件 URL。也可明确选相对路径或绝对文件 URL；跨磁盘等无法相对化时会回退文件 URL。
- **相对前缀**控制是否为非父级相对路径加上 `./`。**路径转义**控制空格和非 ASCII 字符是否编码；关闭后仍保留必要的 URL/Markdown 分隔符编码。

复制图片需先保存文档；引用原图在 auto/absolute 下允许未保存文档，relative 仍须先保存。原图被移动或删除后，引用会失效。当前接受的本地图像格式见文件选择器，单张不得超过 25 MB；不自动上传或下载远程图片，也没有文档级 YAML 图片目录覆盖。

移动或分享文档时，把 `.md` 文件和相关资源目录一起带走。跨目录另存为会复制识别到的文档目录内相对图片，并保留相对位置；上级路径、符号链接和超限图片改为原位置文件 URL，缺失图片保留原引用。目标已存在不同内容的同名图片时会提示失败，避免覆盖。该迁移覆盖识别到的图片地址，不保证任意 Markdown/HTML 中的所有路径语法均已兼容。随附示例的 `assets/` 也需保留。

阅读模式单击普通图片可打开查看器；链接图片单击打开链接，Alt + 单击查看图片。查看器可选择“适应窗口”“100%”或加减缩放，按住图片拖动查看，`Ctrl/Cmd + 滚轮` 缩放；普通滚轮用于滚动。双击在适应与原始比例间切换，Esc 关闭并回到之前的焦点。书写时普通单击仍用于选中图片，不会强制打开查看器。

## 保存与草稿

首次保存会选择文件位置。关闭、新建或打开其他文档时，如存在未保存修改，应出现保存、放弃或取消的选择。

草稿恢复用于找回中断前的内容。恢复副本应先核对，再通过保存或另存为确认目的文件；不要把恢复提示视为已经写回原文件。

新文档默认使用 UTF-8。打开已有文件可保留 UTF-8、UTF-16 LE/BE、GB18030、Big5、Shift_JIS、EUC-KR 编码及 BOM、换行风格；未改动的保存保留原始字节。点击底部编码名称，可确认推测结果、按选定编码重新读取，或选择“下次保存转换为此编码”。重新读取前会处理未保存修改；转换编码需保存后才写入磁盘。自动推测出现问号或提示时应检查中文内容，必要时手动重读。目标编码无法表示某个字符时会报错，不会静默替换为问号。

偏好设置中可启用自动保存，并设置 1—30 分钟的间隔。自动保存仅处理已有文件路径且存在修改的文档，输入法组合期间暂不保存；未命名文档仍使用恢复草稿。自动保存与崩溃恢复是两种功能。

## 偏好设置

使用更多菜单中的“偏好设置”，或按 `Ctrl/Cmd + ,`。窗口按外观、排版、表格、阅读、编辑、快捷键、通用、Markdown、代码、数学和图片分类。可按名称、配置键和说明搜索；窗口内 `Ctrl/Cmd + F` 聚焦设置搜索，Esc 关闭并返回原编辑位置。0.4 设置模型共有 68 项，其中 66 项可见，2 项用于保存当前排版方案标识和自定义方案数据。

排版方案提供“日常书写”“技术文档”“中文长文”“紧凑排版”，可命名保存当前显示配置；内置方案可复制后调整。方案包含字体、字号、正文宽度、行高、中西文间距、标点悬挂、首行缩进、对齐和表格呈现。每项旁的复位按钮回到当前方案基准；恢复应用默认值会重置整份设置。样例支持折叠，以及与打开设置前的显示并排对照，样例公式仅为排版示意。

中西文可使用不同字体；选择本机字体前请确认它在当前系统可用。优化断行用于只读阅读，按段落选择行的断点；复杂内联内容、过长段落或其他不适用内容保留浏览器排版。间距、悬挂和断行不会向正文插入空格或换行。配色可选墨页、黑白、Solarized、Nord，也可在配色编辑器中保存自己的主题。

设置更改会自动保存。输入无效值时会就地提示，失败时保留上次已保存的配置；修正标出的选项后再关闭。窗口底部提供：

- **恢复默认**：需要二次点击确认，恢复墨页应用默认值，保留文档内容。
- **导入设置**：从文件选择器导入墨页 JSON 设置，校验成功后整份替换；0.2.0 的有效 schemaVersion 1 设置可导入，新增选项补为当前默认值；不接受把 Typora 的配置文件直接当作墨页设置导入。
- **导出设置**：通过文件选择器导出当前已保存的墨页设置，便于备份或迁移。
- **配置文件 / 重读配置**：用系统关联程序打开本机配置文件，手动编辑后重新读取；有效外部更改也会自动同步。无效配置会提示并保留上次有效值。

应用设置保存在自身用户数据目录中的 `settings.json`。损坏文件会保留为带 `settings.invalid-` 前缀的副本，再使用应用默认值；修复或恢复前请保留副本。

外观、编辑、代码和通用选项通常在保存后立即生效。**Markdown 和数学设置需要点击“重新载入”才影响当前编辑器**；待应用时，设置窗口和书写区上方会显示提示。更改会先保存到配置，重新启动也会采用新配置。重新载入会保留原文、未保存标记、模式、光标/选区及滚动位置，**撤销历史会重新开始**，建议先完成需要撤销的编辑。

正在使用输入法选词时，请先完成或取消组合，再修改设置或重新载入。完整设置范围见 [0.4.0设置进展](0.4.0设置进展.md)，新增体验与边界见 [Telari体验对照](Telari体验对照.md)。默认值是墨页默认值，尚未逐项对照 Typora。

## 公式设置

默认公式引擎为离线 MathJax 4.1.3，支持本地宏、公式编号及附带的 `begingroup`、`bboldx`、`mhchem` 资源，可另启用本地 physics 扩展。可在数学设置中切换 KaTeX；更改后按提示重新载入。

公式宏填写 JSON 对象，宏名使用英文字母，不带反斜杠。例如 `{"RR":"\\mathbb{R}"}`，正文公式中使用 `\RR`。需要参数的 MathJax 宏可写成 `{"bold":["\\mathbf{#1}",1]}`，并可提供第三项作为可选参数默认值。应用只解析数据，不执行 JavaScript。

自动编号依赖 MathJax 引擎，可在“所有块公式”和“AMS 环境规则”之间选择；自动编号关闭时，编号规则不生效。physics 也仅用于 MathJax。KaTeX 兼容路径不会提供相同的编号和可选参数宏机制；切换引擎后需检查公式，不应将两种引擎视为完全等价。与最新 Typora 全部数学配置和公式行为的逐项对照仍未完成。

超宽块公式可选局部横向滚动或缩小以适应正文。阅读模式还支持 `\(...\)` 行内和 `\[...\]` 块级公式写法，分别遵循行内与块公式开关；这是只读阅读支持，书写区仍需按其现有语法行为编辑。阅读公式使用独立编号过程，进入阅读不会推进书写区公式计数。渲染失败会显示可复制的公式源码，请按错误提示修正。

## Markdown 显示选项

行内 `$...$`、`$$` 块公式和语言名为 math 的代码围栏预览分别有独立开关。关闭其中一种不关闭另外两种；关闭预览保留可编辑源码。连续空白和单个换行选项只改变书写区显示，不改 Markdown 原文、显式换行或代码。所有 Markdown/数学选项均须按提示显式重新载入。

## 离线使用

编辑器、公式、图表和代码高亮的运行资源随应用提供。本地图像可离线使用；文档中直接引用的远程图像需要网络。

## 0.5 新增操作

更多操作中可打开最近文件，搜索、移除或清空记录；这些操作不会删除文档。偏好设置的通用分类可切换中英文，用户内容与文件名保持原文。

较大TXT会自动使用源码模型与独立分段阅读，可从大纲跳章节、用分段按钮或首尾键导航；查找覆盖整篇，Ctrl/Cmd+A后复制得到整篇原文。TXT独立预设在阅读分类设置；下一篇提示也可关闭。普通打开文件不需先选文件夹，即可使用同目录前后篇。

PDF导出可选择纵向或横向和8—30毫米页边距。超出长文导出预算时会拒绝，不会仅导当前可见片段；将需要的章节另存为较小文件后再导出。Linux发布包可通过更多操作的系统缩略图入口显式启用或移除文件管理器缩略图。

Ctrl/Cmd+W在多个工作区标签时仅关闭当前标签，剩一个时关闭窗口；标签右侧×可只关闭最后一个标签并留空白文档。关闭脏文档会确认，取消保留当前编辑。窗口大小与普通位置会记忆，移除显示器后回到可用区域。
