# 墨页 0.2.0 开发预览验收记录

日期：2026-10-23。状态：**尚未达到最新版 Typora 全设置及全部合法配置下行为一致的验收目标**。本报告记录实际完成的功能验证，不能将通过项换算成原版设置兼容率。

## 本轮实现

新增偏好设置窗口及 34 项墨页应用设置，支持分类、搜索、原子持久化、重置、导入导出与旧版外观偏好迁移。设置列表、应用方式和限制见 [0.2.0设置进展](0.2.0设置进展.md)。34 项不是 Typora 设置总数，其默认值仍未经过原版逐项实测。

外观与部分编辑选项即时生效；Markdown/数学设置需点击“重新载入”。重载前冻结文档动作并禁用编辑，使用冻结的配置快照，保留原文、修改状态、模式、光标和视口，重新开始撤销历史。已测异步配置加载期间输入、模式切换、排队新建以及后续配置变更，不覆盖文档或误将新配置标为已应用。

默认公式引擎为离线 MathJax 4.1.3，含 NewCM 动态 SVG 字体及化学/扩展字体、宏、公式编号。KaTeX 为附加兼容选项，自动编号只在 MathJax 下生效；KaTeX 不完整支持可选参数默认值的宏。使用相同引擎大版本不构成 Typora 数学行为相同的证明。

修复了剪贴板中链接文字丢失和私有编辑标记泄漏的问题，复制/剪切可提供可见纯文本或 Markdown，同时输出语义 HTML；剪切删除可撤销。自动配对保留 Unicode 字素、反向选区、粗体和链接，区分代码围栏/行内代码及关闭的语法开关。

自动链接在即时渲染区通过独立普通解析器及 CSS Highlight 范围层实现，排除代码、数学和显式链接，Ctrl/Cmd 点击经原生白名单打开。范围层不插入 DOM 锚点，因此不会把裸 URL 改写为显式 Markdown。候选筛选及文本缓存避免长篇无链接正文反复进入解析器。当前域名识别遵循所捆绑 Lute 的规则，尚未证明与 Typora 相同。

另修复切换代码主题/行号时已有 `hljs` 类导致语言误判、丢失高亮；空选区插入默认语言代码块重复整篇文档；以及折叠公式/代码隐藏源码标记被通用 padding 样式撑成空色块。

## 已执行测试

- `npm test`：66 项通过，覆盖文件、恢复、图片迁移、文档状态和设置存储。设置写入失败、版本冲突、无效导入、步长、未知字段和危险对象均不会部分应用。
- `npm run test:ui`：126 项真实 Electron 功能检查全部通过：原有编辑 49、原生设置 8、离线 MathJax 6、设置界面与行为 39、真实文档字体/数学设置 4、配对边界 12、自动链接边界 5、折叠公式与代码排版 3。报告位于 `tests/*-report.json`，完整日志为 `artifacts/ui-0.2.0-final.log`。
- 设置检查包括主题与布局、真实系统剪贴板 MIME、图片复制/引用、自动保存、进程重启、旧偏好一次性迁移、导入/导出、原文/CRLF 保留及重载竞态。自动保存使用虚拟时间推进后验证实际文件写入；不是等待一整分钟的实机计时。
- 新增真实文档检查覆盖正文字体、MathJax→KaTeX→MathJax、宏新增/移除和编号开关/跨文档重置。自动链接检查覆盖实际 IR 根结构、精确高亮范围、普通点击与 Ctrl/Cmd 点击、显式重载、编辑撤销、组合输入延期、长篇无链接跳过解析，以及刚改完 URL 立即点击时打开新目标。
- MathJax 检查在会话级阻止 HTTP(S)，覆盖 worker 请求；六项均通过，页面/控制台错误和远程请求为 0，所测动态字体均使用本地资源。
- 配对检查使用真实按键，覆盖 Emoji、组合音符、ZWJ、反向选区、富格式、不同字符/长度及缩进的围栏、行内代码、禁用公式和删除配对的撤销/重做。
- 已目视检查 1280×860 设置窗口；520×700 布局无横向溢出。设置窗口原型的更窄 420px 检查为辅助证据，不替代整个应用的全部窄窗行为验证。

这些用例检查墨页自己的功能。Undo 对照使用墨页同序列控制组；组合输入为合成事件。它们不代表 Typora 差分、真实系统中文输入法或 Windows/macOS 认证。

## 原版基准与当前阻断

官方整体稳定发布页顶部版本为 1.14.10。本轮实际取得的官方 Linux x64 浮动包，版本元数据为 **1.14.9**，与官方 APT 最新 amd64 条目 1.14.9-1 一致。不能将它重标为 1.14.10。主域 APT 索引本轮观测的最新 amd64 条目也是 1.14.9-1，但尚未确认所有 Linux 发布渠道均无 1.14.10。来源、大小、SHA256 和启动错误记录在 `tests/typora-reference-report.json`。

原版调试启动拒绝调试参数；普通启动在单实例初始化时因本环境禁止 Unix socket 而终止。没有绕过这些限制，没有采得原版设置 UI、默认值或完整操作基线。Windows/macOS 原版实装对照也未取得。原版程序未进入墨页源代码或发布归档。只读声明式元数据另得到 10 项高级默认声明和 226 个设置/组/值标签候选，记录在 `tests/typora-settings-metadata.json`；候选标签数不能当作设置总数，声明默认值也不等于运行默认值已验证。

因此，下一项必要的验收证据来自可正常运行各平台最新原版的桌面环境：逐项枚举设置，登记默认值/合法值/依赖/生效时机，并执行相同文档、配置和操作序列。仅靠公开帮助文档不能确认全量设置完整性。

## 尚未完成的能力与验证

完整原版设置清单、默认值和所有依赖尚未枚举；现有专注模式仍是墨页隐藏界面的实现，尚未对齐 Typora 的逐行聚焦行为；高级配置兼容、Typora 主题/CSS DOM 兼容、自定义快捷键、智能标点与严格解析、完整图片上传/路径策略、文件侧栏和导出预设等尚未补齐。这些仍在目标内，不能以旧首版范围排除。

尚未执行 Windows、两类 Mac 的实机测试、真实中文输入法、跨应用系统行为以及各平台完整性能验证。发布包未签名/公证。所有已知缺失和行为偏差均阻断“Typora 全设置兼容”声明，详见 [Typora设置兼容性](Typora设置兼容性.md)。

## 打包与性能

四个 0.2.0 便携包均构建完成：Windows x64、Linux x64、macOS Intel x64、macOS Apple Silicon arm64。每包 777 个应用与资源文件逐字节匹配冻结源码；四包及其压缩包内唯一 ASAR 的 SHA256 均为 `7fd5b26e7c2836b960cb42a8086b9aacec10abe8612bc8de33bf4d4038574f95`。ZIP CRC、完整 gzip CRC、可执行文件架构及压缩包无构建临时件检查均通过。详细包哈希在 `RELEASE-MANIFEST.json` 与 `tests/package-report.json`。

实际 Linux 发布包离线 smoke 通过（8 个图表、5 个公式、本地字体和图片）；设置 39/39、真实文档数学设置 4/4、折叠公式与代码布局 3/3、源码视口 2/2 均通过。已目视检查最终包深色公式和设置界面，折叠源码标记为 0×0，无额外空白色块。Linux 使用隔离测试配置和 headless 运行；未将此结果扩展为其他操作系统或真实输入法通过。

长文性能使用同一最终 Linux 包，在所有构建、压缩与其他测试结束后测量一次。文档包含 100,080 个汉字、100 个代码块及 20 张本地图片，原文及输入完整、全部图片与高亮加载、未观察到视口重置或光标离开视口。结果：

| 指标 | 结果 | 当前门槛 |
| --- | ---: | --- |
| 应用启动到就绪 | 816.8 ms | 低于 2,000 ms |
| 打开文档到可编辑 | 679.3 ms | 低于 2,000 ms |
| 真实 beforeinput 到下一 rAF，P95 | 36.5 ms | 低于 50 ms |
| 页面插入到下一 rAF，P95 | 38.3 ms | 低于 50 ms |
| Playwright 输入/通信/下一帧往返，P95 | **58.3 ms** | **超过 50 ms，未通过** |

`artifacts/performance-report.json` 保留 `editorInteractionPass: true`、**`pass: false`**，不因较快的内部帧指标或热身结果而将整体性能改判通过。rAF 是 headless 渲染调度代理，不是物理显示器呈现时刻；Playwright 提交字符不代表真实中文输入法，文件选择器使用即时测试选择，人工交互时间不包含在打开测量内。早期 0.2.0 中间构建的失败性能样本另保留为 `artifacts/performance-before-marker-layout.json`，不冒充最终包数据；0.1.0 记录见 [0.1.0验收记录](0.1.0验收记录.md)。

当前总体结论仍为**未达标**：端到端性能门槛未通过，原版全量设置枚举、缺失能力及各平台真实差分验收仍未完成。
