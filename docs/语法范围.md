# 0.3.0 语法能力与兼容缺口

墨页 0.3.0 使用 Vditor 4.0.1 的即时渲染编辑内核，桌面环境使用 Electron 45.0.0。本清单记录当前开发预览能力，不能缩小用户要求的全部 Typora 设置与行为目标。0.1.0 的测试继续作为历史证据保留。当前目标见 [Typora设置兼容性](Typora设置兼容性.md) 和 [验收标准](验收标准.md)，实际测试见 [验收报告](验收报告.md)。

## 基础语法

| 类别 | 范围 |
| --- | --- |
| 段落 | 普通段落、软换行、空行、转义、中文与 Unicode |
| 标题 | ATX 一级至六级标题 |
| 行内格式 | 粗体、斜体、删除线、行内代码、嵌套强调 |
| 列表 | 无序、有序、多级嵌套、任务列表 |
| 引用 | 普通引用、嵌套引用、引用中列表和代码 |

| 表格 | GFM 表格、列对齐、单元格行内格式、增删行列 |
| 链接 | 行内、引用式、自动链接、文档内标题锚点 |
| 图像 | Markdown 图像、本地相对路径、远程 URL、常用 HTML 图像尺寸 |
| 其他 | 水平分割线、Emoji 字符 |

## 扩展语法

| 扩展 | 格式与范围 |
| --- | --- |
| 数学公式 | 默认离线 MathJax 4.1.3，可选 KaTeX 0.16.9；`$...$` 行内、`$$` 块公式和 math 代码围栏分别开关；提供宏、MathJax all/AMS 自动编号与可选 physics 扩展，最新 Typora 全部公式行为尚未对照 |
| Mermaid | 本地打包 Mermaid 11.17.2；已用样本检查 flowchart、sequenceDiagram、stateDiagram-v2、classDiagram、erDiagram、gantt、pie、mindmap；与原版库行为尚未逐项对照 |
| 脚注 | `[^名称]` 引用与 `[^名称]: 内容` 定义 |
| 文内目录 | `[toc]`；从文档标题生成与更新 |
| 元数据 | 文档起始的 YAML Front Matter，`---` 围栏 |
| 高亮 | `==高亮文字==` |
| 下标 | `H~2~O` |
| 上标 | `x^2^` |
| 提示引用 | GFM 风格的 NOTE、TIP、IMPORTANT、WARNING、CAUTION 引用，按样本验收 |

Mermaid 的其他图表类型可能由内核识别，目前未执行测试；这是证据缺口，不是将它们排除出最新 Typora 兼容目标的理由。图表中的联网资源需另测其加载策略。

0.3.0 可分别开关行内数学、块数学、math 代码围栏、上下标、高亮、自动链接、目录、脚注及图表，并提供连续空白/单个换行显示选项。语法与数学设置先保存，再显式重新载入编辑器生效；原文、修改状态和编辑位置保留，撤销记录重新开始。关闭块公式、math 围栏或图表预览后，内容保留为可编辑源码。空白显示使用 CSS white-space，不改写 Markdown、显式换行或代码。所有开关与原版在全部组合下的行为一致仍待验证。

MathJax 本地资源包括 `begingroup`、`bboldx`、`mhchem` 及相应字体，可另开启本地 physics 扩展。宏为 JSON 数据，支持文本或参数定义。自动编号、编号规则、physics 与可选参数宏依赖 MathJax；自动编号关闭时 all/AMS 规则不生效。KaTeX 路径存在能力差异。采用 MathJax 4 本身不能作为与 Typora 数学设置完全兼容的证明。

## HTML

已检查的常用内容标签：`u`、`br`、`img`、`span`、`kbd`、`sub`、`sup`、`details`、`summary`。HTML 源码应可修改；图像 `width`、`height` 等常用尺寸属性按样本检查。

原始 HTML 的显示受到当前清理规则约束，不能把任意网页直接当成完整应用嵌入。当前不执行文档中的脚本、事件处理器、任意 iframe 或网页应用；这记录现状，相关设置及同平台原版行为仍属于待对照项目。未支持语法仍须在 Markdown 文件中保留原文，不能因为无法显示而删除用户内容。

## 文件与互操作

- 主文件格式为 UTF-8 Markdown；打开后未编辑直接保存，应保留原始字节。
- 已有文件的 UTF-8 BOM、CRLF/LF 按约定保留；不承诺任意编码自动转换。
- 即时渲染编辑可能对编辑过的内容作必要 Markdown 规范化；允许范围必须在验收中记录，不得静默改写无关内容。
- 本地图片随文档及资源目录一起移动。跨目录另存时复制源文档目录内的相对图片；上级目录图片、符号链接与超过25MB的图片保留为指向原位置的file URL，不自动搬运。远程图像的离线可用性取决于其是否已保存为本地文件。
- 从文件插入图片时，可选择复制或原位置 `file:` 引用。截图/剪贴板图像仍保存为文档资源；资源目录支持 `${filename}` 文档内相对模板，可选 auto/relative/absolute 路径、相对前缀和转义；拖放/剪贴板字节流仍落盘。尚无完整图片上传、远程复制及文档级路径覆盖策略。
- Mermaid、公式、代码高亮所需脚本、样式和字体随程序提供，不在运行时从 CDN 下载。

当前 47 项墨页设置及 27 个自定义快捷键命令见 [0.3.0设置进展](0.3.0设置进展.md)。输入时智能标点只覆盖书写模式单字符输入，排除源码、粘贴、组合输入和代码/公式/YAML/HTML/链接目的地址等场景；不改写已有文档。Markdown 横线等结构输入会保留 ASCII 连字符。渲染转换、一般 Unicode 解析重映射和系统引号样式尚未实现或对照。

尚未完成完整 Typora 设置清单及默认值映射、高级配置、完整主题/CSS DOM 与快捷键目录兼容、智能标点渲染/重映射及严格/传统解析、完整图片上传与全部来源/路径策略、文件侧栏、导出预设和 YAML 设置覆盖。新目标涉及这些设置时须补齐对应能力，不得再用旧首版范围排除。应用代码和图标独立制作，具体兼容机制需按原版行为验证。
