# 墨页 0.4.0 设置实现进展

更新日期：2026-10-24（Asia/Shanghai）。本版仍为开发预览，原有 Typora 最新稳定版全部设置及相应行为一致的目标继续保留。本轮根据 Telari 公开体验说明独立实现排版与阅读功能；未取得 Telari 原版运行差分证据，不能把墨页内部回归通过等同于两款原版行为一致。

当前设置定义由 **47 项增至 68 项**。原有 47 项的键、默认值和基础说明见 [0.3.0 设置进展的设置表](0.3.0设置进展.md#47-项应用设置)；本文件仅列新增的 21 项以及命令目录变化。68 项中，66 项使用普通设置字段，2 项方案元数据由方案管理卡操作；这些数量不是 Typora 或 Telari 的设置总数。

## 方案、导入与显示边界

内置方案为日常 `daily`、技术 `technical`、中文长文 `book`、紧凑 `compact`。日常方案保留旧版默认的 17px、780px、1.85 行高、默认字体和正文宽网格表格。方案只收录字号、宽度、行高、字体、排版及表格显示字段；不收录编辑开关、快捷键、原文、文件路径和数学宏。逐项恢复以**当前方案的字段起点**为准，未命名调整保留“已调整”状态。删除正在使用的自定义方案会将方案引用回退为日常，并保留当前显示值供用户继续比较。

方案 JSON 严格校验对象、ID、名称和允许字段，拒绝未知字段、重复 ID/名称、非数据属性、非法字体及越界数值。自定义方案最多 32 个，名称最多 40 字符；JSON 字段最多 65536 字符仍须服从**整份设置文件 64 KiB** 的限制，不能将单字段上限理解为保证任意最大组合都能导入。设置文件保持 `schemaVersion: 1`，旧版有效设置缺少的新键补为本版默认值；错误导入不部分应用。

中西文间距、字体分工和段落显示不写入原文。当前随包 Chromium 已验证支持 `text-autospace`，不支持原生 `hanging-punctuation`；后者只能按已支持的具体显示路径记录。`justify` 使用浏览器断行，不能称为 Knuth–Plass。`optimal` 在独立只读阅读 DOM 中执行有界 box/glue/penalty 动态规划，带相邻行适配度惩罚及中文行首尾限制；它不是 TeX 的像素级等价实现。

整段优化仅处理适合的普通段落，每段最多 4096 个 UTF-16 单元、700 个分词单元，每文档最多 18000 个字符预算；包含复杂代码、公式、显式换行或不支持方向的段落回退为浏览器排版。显示行包装不插入软换行字符，复制时移除显示包装并保留文字及语义格式。窗口、字体或内容改变会重新测量；颜色变化不应重建段落。

## 命令目录由 27 项增至 33 项

原有 27 个稳定命令 ID 及其默认快捷键沿用 [0.3.0 的命令表](0.3.0设置进展.md#快捷键命令与配置)。`editor.keyBindings` 现接受下列新增 6 个 ID；空字符串表示未绑定，菜单入口仍可用。命令 ID 是墨页自己的配置格式，不是 Typora 配置文件导入格式。

| 新命令 ID | 操作 | Windows / Linux 默认 | macOS 默认 |
| --- | --- | --- | --- |
| `reading` | 切换阅读模式 | 未绑定 | 未绑定 |
| `workspace` | 打开文件夹 | 未绑定 | 未绑定 |
| `previous-file` | 同目录上一个文件 | 未绑定 | 未绑定 |
| `next-file` | 同目录下一个文件 | 未绑定 | 未绑定 |
| `export-pdf` | 导出 PDF | 未绑定 | 未绑定 |
| `export-image` | 导出图片 | 未绑定 | 未绑定 |

阅读态 Space / Shift+Space 和 PageDown / PageUp 的整行翻页属于阅读交互规则，不增加此稳定命令目录的数量，也不占用编辑态空格输入。文件夹预览/固定标签、图片缩放拖动、表格选择复制和 PDF/图片导出是新增交互能力，不额外计作设置项。

阅读态支持常见 AI 公式分隔符 `\(...\)` 与 `\[...\]`，分别依赖已重新载入的行内/块级数学开关；代码、HTML、URL 与已转义字面量保持字面内容。此处理只作用于独立阅读副本，复制保留原始分隔符，不表示书写内核已具备同一额外语法。读取渲染使用所选本地引擎；MathJax 使用独立阅读文档统一编号，不重置编辑器编号计数器。超限和渲染错误保留源码；这部分的实际执行结果以本轮测试报告为准。

阅读公式统一限制单式最多 4096 个 UTF-16 单元、每次阅读重建最多尝试渲染 512 个公式、总 TeX 最多 65536 个 UTF-16 单元；这些限制同时作用于普通 `$`、`$$`、math 代码围栏及额外分隔符。超限公式保留对应原分隔源码并记录原因，不送入渲染引擎；单式过长不消耗后续合法公式的预算，总预算不足时仍可继续渲染能够容纳的较短公式。

文件读取后编辑模型统一使用 LF；公式分隔符和内部空白以该模型原文为准。文件原有 CRLF/CR 换行及编码元数据由文件存储层保留，保存时恢复，不把剪贴板中的 LF 当作磁盘换行改变。

本文件说明设置结构和实现范围。测试平台、源代码与发布包运行结果、性能及尚未完成的原版差分证据，统一见 [验收报告](验收报告.md) 和 [Telari 体验对照](Telari体验对照.md)，不以设置数量或成功构建替代运行验收。

新增六个命令默认不占用快捷键，确保0.3已经合法的自定义组合键在升级后仍合法；例如旧版将Ctrl+Alt+R绑定为重做时继续保留，阅读模式可另行绑定。
