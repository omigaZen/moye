# 墨页 0.4.0 开发预览验收记录

日期：2026-10-24（Asia/Shanghai）。本轮在原有 Typora 编辑目标上加入 Telari 公开体验清单。总体仍为**开发预览**：尚未完成 Telari 42 个行为组的全部细节，也未达到最新版 Typora 全设置、全合法配置下的行为一致目标。应用自测、原版差分、源码运行、实际发布包运行分别记录。

## 实现范围

设置由47项增至 **68项（66项可见、2项方案状态键）**，可配置命令由27增至 **33个**。新增合法值、生效时机与限制见 [0.4.0设置进展](0.4.0设置进展.md)；42组逐项状态见 [Telari体验对照](Telari体验对照.md)。

- 排版：内置及命名方案、复制/删除、逐项恢复、设置样例，中西文与等宽字体分工、混排间距、段落缩进、配色及有界段落级断行。复杂段落回退浏览器排版，不宣称与CoreText/TeX逐字形相同。
- 阅读：独立只读副本、整行翻页和上下文重叠、沉浸界面、语义阅读锚点及受限位置记忆、TXT原文/Markdown选择、章节大纲、图片缩放拖动。源码着色保留原生textarea的光标、选区和撤销。
- 内容：后台Worker代码着色、语言角标和复制；Mermaid错误/限额回退；MathJax/KaTeX离线数学、额外公式分隔符、独立编号、错误源码复制、超宽公式局部显示；8种非Mermaid图表可从最新源码独立绘制。
- 表格：自然/正文/窗口宽、局部横滚、网格/三线、显示对齐、整表与矩形区域TSV/HTML复制；显示选项不改源文列对齐。
- 文件：工作区树、预览及保留标签、自然顺序前后文档、展开目录监控刷新、外部修改提示。UTF-8/UTF-16/GB18030/Big5/Shift_JIS/EUC-KR可读写；猜测须确认，显式编码按文件哈希跨重启记忆，未提交转换不改变磁盘读取编码。
- 设置与主题：受限TOML主题、继承、文件监控、草稿及冲突保护；配置文件定位和手动重读，坏外部JSON保留最后有效设置；组合输入期间延后显示更改。
- 导出：PDF和整篇PNG，纸张/宽度/倍率/配色；隔离窗口禁用JavaScript、Node及外网。导出等待数学与图表计算，不修改当前原文、dirty和撤销。图片超限拒绝；打印单独恢复表格分页规则。

修复了源码打开/重载无尾换行时被规范化补LF、切换慢文件期间可能丢失新增输入、导出期间关闭窗口留下关闭锁、未保存编码转换后按错误目标编码重新读取等实测或审查问题。公式预览单击的焦点争抢通过真实滚动78px再单击的回归确认修复；新增命令默认不绑定，保留旧版自定义快捷键的合法性。工作区预览现全局唯一，预览与保留标签合计最多20个；经由非活动预览替换、切换保留标签和连续Enter打开的实际边界检查通过。

## 最终性能

最终实际Linux包的**首次完整采样通过**，未为通过重采或放宽门槛。

| 指标 | 毫秒 | 原门槛 |
| --- | ---: | ---: |
| 启动至ready | 851.1 | ≤2000 |
| 长文打开至可编辑 | 645.7 | ≤2000 |
| 真实beforeinput至页面帧P95 | 19.2 | ≤50 |
| 页面插入至帧P95 | 19.1 | ≤50 |
| 自动化输入端到端P95 | 34.3 | ≤50 |

20张本地图像和100个代码块均加载，原文完整，60次提交输入计数准确，长文中段光标可见，观察到的滚动偏移为0px。

另行启动同一实际包对相同长文采集Linux内存，未重复延迟测试：进程RSS合计 **670.6 MiB**，PSS合计 **442.2 MiB**。RSS包含共享页重复计数，PSS按比例分摊；这是稳定后单次快照，不是峰值或跨系统上限。Electron工作集API在本环境返回全零，因此不能将该零值称为实际占用；真实`/proc`采样与可复现脚本分别为 `artifacts/memory-report.json`、`tests/editor-memory.cjs`。

性能样本含100080个汉字、100个代码块和20张本地图像，固定1280×860视口。最终采样使用实际Linux包，在构建/压缩/功能测试结束后运行；不放宽50ms门槛，不用页面内部耗时替代端到端耗时。原始数据为 `artifacts/performance-report.json`，上一版数据另存 `performance-0.3.0-report.json`。物理屏幕呈现延迟、真实输入法和各目标系统性能仍待对应机器验证。
