# Typora 全设置与编辑行为兼容验收

更新日期：2026-10-25（Asia/Shanghai）。用户要求：支持最新版 Typora 的所有设置，并使所有合法设置下的编辑表现与同平台 Typora 一致。本文件取代早期首版范围中的收缩约定。当前 0.5.0 已实现 72 项墨页应用设置（70 项可见、2 项方案状态键）、设置窗口和持久化，并提供 36 个命令的快捷键配置；仍未达到全量原版兼容。72 项不是 Typora 设置总数，36 个命令也不是其完整快捷键目录。0.1.0/0.2.0 保留为历史功能预览证据；当前新增设置、合法值和依赖见 [0.5.0设置进展](0.5.0设置进展.md)。

## 对标版本

- 当前官方稳定发布页顶部版本为 **1.14.10**。本轮以最新正式稳定版为基准，不自动采用开发通道。
- 版本来源：<https://typora.io/releases/stable?no-warning=>，核对日期 2026-10-24（Asia/Shanghai）。
- 官方页面版本已核对。已成功从官方 `download.typora.io` 下载原版 Linux x64 包，实际包元数据为 **1.14.9**，SHA256 为 `06f03e6dee1f48126e62680ecd8e0551053681951d802d8ee433f96dae9fa045`；官方 APT 索引的 amd64 最新项也为 1.14.9-1。不能把此包标成 1.14.10，或把网页核对写成原版运行验证。
- 原版拒绝生产环境调试启动；普通原版启动又被当前主机禁止 Unix socket 的限制阻断，尚未取得原版设置 UI、默认值和行为基线。未绕过其调试保护、授权或试用限制。Windows、macOS 同样没有原版运行证据。详细下载、版本及启动记录见 `tests/typora-reference-report.json`。
- 后续每轮验收重新检查最新稳定版。出现新版本时，登记新增、修改、删除设置和行为变化，冻结新的版本及配置，再运行对照；既有报告保留原版本，不将其直接改名为新版本通过。

## 全设置的含义

覆盖原版同平台的全部用户可配置入口：偏好设置、菜单内可持久选项、高级配置文件、快捷键、主题与用户 CSS、文档级 YAML、相关启动参数，以及参与行为的系统级选项。设置涉及文件管理、图片处理、导出、拼写等能力时，相关能力也进入目标，不能沿用早期首版的排除约定。

以下仅为官方文档已确证的**分类索引，不是完整逐项清单**。未取得实际版本全量设置清单前，完整性状态必须保持“未确认”。

| 类别 | 待逐项登记与对照的内容 |
| --- | --- |
| 通用与启动 | 语言、启动/恢复、最近文件、更新与通用偏好、恢复默认 |
| 外观与主题 | 主题、明暗模式、字体、缩放、写作区域、浮动工具栏、自定义 CSS 及加载顺序 |
| 编辑行为 | 自动配对、包裹选区、智能引号/破折号、缩进、列表、粘贴、专注和打字机模式 |
| Markdown | 严格模式、自动链接、扩展语法开关、传统行内解析、换行/空白、切换设置的应用方式 |
| 代码块 | 行号、长行换行、缩进、默认/最近语言、语法创建与菜单创建差异、代码主题 |
| 数学与图表 | 行内数学、分隔符、兼容模式、编号、宏和包、图表开关与配置 |

| 文件与侧栏 | 默认扩展名、拖放、文件树/列表、排序、隐藏/非 Markdown 文件和 glob 过滤 |
| 剪贴板 | 默认纯文本格式、Markdown、富文本、HTML、无主题复制及粘贴策略 |
| 拼写与系统联动 | 语言/字典、学习词、系统拼写、文本替换、输入法、平台专属项 |

## 每项设置的必填记录

每项须有稳定 ID、原始名称和入口路径、Typora 实际配置键（尚未确认写未知）、平台/版本条件、类型、全部合法值或范围、实测默认值、无效值处理、保存位置与重启恢复、生效时机、作用范围、文档级覆盖、依赖/互斥项、行为影响和来源。

分别记录“已枚举”“已实现”“已原版对照”。只显示同名复选框、只写入配置但不改变行为，均不算支持。设置变更后的即时应用、重载或重启提示也须与原版实测一致。

## 行为对照

在同系统、同字体、同缩放、同窗口尺寸、同输入法和同配置下，用同一文档执行相同逐键/鼠标操作。每一步比较：

1. 文档与保存后的 Markdown、编码、换行、资源处理结果。
2. Markdown 标记显隐、渲染更新时机、块结构和布局。
3. 光标、选区两端及方向、焦点、滚动位置和命中区域。
4. Enter、Backspace、Delete、方向键、Tab 等在块内和边界的行为。
5. 真实输入法的选词、取消、候选框位置和提交后撤销。
6. 撤销分组、重做、剪贴板的各 MIME 数据和跨应用粘贴。
7. 切换设置、切换文档/源码模式、保存、恢复和重启后的状态。

最终 Markdown 相同或最终截图相似，不能替代中间操作一致。视觉阈值、环境差异须事先记录，不能事后扩大阈值掩盖差异。任何行为差异保留最小复现，修复后重新对照。

## 配置组合和可证明范围

目标覆盖全部合法配置，不因测试预算将“所有设置”缩成默认设置。验证账目必须分开列出：单项全部值、相互依赖组、两两组合、重点多项组合、可穷举组，以及未验证组合。

有限且可枚举的相互影响组应穷举；两两覆盖和抽样仅是发现问题的方法，不能称为“所有组合已通过”。切换顺序及历史状态也须纳入，因为相同最终设置可能来自不同操作过程。

自定义 CSS、任意字体、自由文本、外部命令及系统环境形成开放输入空间，无法靠有限测试穷尽证明绝对等价。必须说明实现的兼容机制和已验证样本；没有证明的部分保持“未证明”，不改写为支持所有输入的保证。若最终要求是数学意义上对任意输入、任意配置均绝对一致，当前项目不能作此保证。

## 现有实现的结构性缺口

0.5.0 已有 72 项应用设置注册表、可搜索偏好面板、原生原子保存和导入/导出/重置。保持 schemaVersion 1，读取或导入 0.2.0 的有效设置时，以当前墨页默认值补齐新键；这不表示两版完整配置下的行为已经等价。Markdown/数学设置全部先保存，再显式重新载入，保留原文、修改状态和编辑位置，撤销记录重新开始。这些是墨页机制，尚未逐项证实与原版一致。

专注模式已从只隐藏控件扩展为当前语义块/行以外内容的弱化显示，使用 CSS Custom Highlight 和源码显示遮罩；打字机模式增加鼠标定位居中选项。该机制不是 Typora DOM/CSS 兼容层，全部块类型、主题和选区行为仍须对照。

快捷键使用稳定命令 ID 的 JSON，同时更新原生菜单与编辑区，当前覆盖 36 个命令；不直接导入 Typora conf.user.json 或按原版菜单名映射。智能标点目前只做书写模式单字符输入转换，跳过源码、粘贴、组合输入与代码/公式/YAML 等内容，并保护 Markdown 结构；原文渲染转换、一般解析重映射、系统引号样式和全部撤销行为仍待补齐或对照。

默认公式引擎为本地 MathJax 4.1.3，KaTeX 可选。已有宏、all/AMS 编号、physics 开关，数学代码围栏与行内/块公式独立；公式能显示不等于数学配置和行为兼容。连续空白与单个换行只改变书写区显示。当前打包 Mermaid 为 11.17.2，官方 1.13 记录为 11.13.0；版本较新也不能替代行为验证。

图片已支持文档内相对目录模板、auto/relative/absolute 路径、相对前缀、转义和文件选择器本地来源开关。拖放与剪贴板字节流仍须落盘；完整来源策略、远程复制、上传器和 YAML 覆盖尚未完成。

主要剩余缺口包括：原版完整设置枚举及实测默认值、高级配置兼容、完整主题/CSS DOM 和快捷键目录兼容、智能标点渲染/重映射、严格/传统解析规则、完整图片处理、文件树、导出预设、文档级 YAML 设置、真实系统输入法，以及 Windows/macOS/Linux 同平台原版与墨页的实机对照。它们仍属于验收目标，不能作为范围外项目排除。

需先取得原版各平台设置及行为基线，再决定保留、修改或替换编辑内核；不得为了沿用 Vditor 缩小兼容目标。原版运行证据暂缺时，可以实现基础设施，但不能猜测后标记为原版对照通过。
